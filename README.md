# Groceries checklist

Phone-friendly grocery inventory with **par (target)** levels and **on-hand** counts.

- Adjust on-hand with − / + (saved on this phone only)
- Tap a target to edit par, unit, name, or category
- **Make shopping list** builds a list of items below par (qty to buy = target − on-hand)
- Share / Copy for the shopping list or full inventory

Published via GitHub Pages: https://janbot78.github.io/groceries-checklist/
